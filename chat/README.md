# Chat Static - GitHub Pages

Ứng dụng chat đơn giản sử dụng localStorage, có thể deploy lên GitHub Pages.

## Tính năng

- ✅ Chat với localStorage (không cần server)
- ✅ Lưu tên người dùng
- ✅ Lưu tin nhắn khi refresh trang
- ✅ Xuất tin nhắn ra file .txt
- ✅ Xóa tin nhắn
- ✅ Giao diện đẹp, responsive

## Cách sử dụng

1. Mở `index.html` trong trình duyệt
2. Nhập tên của bạn
3. Gửi tin nhắn
4. Tin nhắn sẽ được lưu tự động

## Deploy lên GitHub Pages

1. Tạo repository mới trên GitHub
2. Upload các file: `index.html`, `app.js`, `styles.css`
3. Vào Settings > Pages
4. Chọn source: Deploy from a branch
5. Chọn branch: main
6. Save

Website sẽ có địa chỉ: `https://username.github.io/repository-name`

## Lưu ý

- Tin nhắn chỉ lưu trên máy local (localStorage)
- Không có tính năng real-time
- Mỗi người dùng chỉ thấy tin nhắn của mình

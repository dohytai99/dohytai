AutoHotkey Script Installer

This installer will help you set up the "Hold C to Send Q+Z" script.

Installation Steps:

  1. First, install AutoHotkey if you haven't already
  2. Then, download and run the script
1. Download AutoHotkey 2. Download Script

After installation, the script will run in the background.
You can find it in the system tray (bottom-right corner).
